# AIWG 2026.9.16 — Grok Bot goes stable

**Release date:** 2026-09-17

**Channel:** stable

Grok Bot is now a stable AIWG provider: skills deploy through a fail-closed
skills root, the wizard and schemas know the harness, sessions can import via
manual export, and a cloud-session global install path loads AIWG the same way
other providers do.

## What else ships

Session export can carry exact attachment and registered-output bytes as
Fortemi BLAKE3 blob sidecars (`--include-bytes`), refuses silent overwrite or
post-plan drift, and accepts current Hermes JSONL exports. Clean-install
steward repairs close registry, providers-list, doctor, and backup-gitignore
gaps for grokbot. Cockpit verifies browser-bound desktop delegation over mTLS.

## Try it

```bash
npm install -g aiwg@2026.9.16
aiwg use sdlc --provider grokbot
```
