# AIWG 2026.9.21 - Decision runtime, effect ledger, and Muse Code provider

AIWG 2026.9.21 ships the Jev decision platform runtime (disabled by default,
experimental where noted), the effect ledger foundation, and the experimental
Muse Code provider verified against Muse Code 1.4.0.

## What changed

- **Jev decision platform:** the decision runtime with mandatory state
  projection for network egress, review lifecycle (D10/D11), trace recording,
  and telemetry runbooks. Several entries close offline gaps only; remaining
  live qualification is tracked in the follow-up issues named in each entry.
- **Effect ledger foundation:** experimental v1 contract with signed effect
  segments, keyring, checkpoints, exit codes, and shared protected-storage
  and signing primitives.
- **Muse Code provider:** experimental `--provider muse` integration —
  registry and capability entries, skill writer, discover-first `AGENTS.md`
  bridge, one managed `SessionStart` hook, opt-in `--mcp` profile,
  export-first session import, and a `muse exec` Ralph adapter, all verified
  against an installed Muse Code 1.4.0.

## Try it

Update with `npm install -g aiwg@2026.9.21`. Muse users can deploy with
`aiwg use all --provider muse` in a trusted workspace. The
[versioning guide](../contributing/versioning.md) describes the stable-channel
policy.

The full change history is in the
[changelog](https://github.com/jmagly/aiwg/blob/v2026.9.21/CHANGELOG.md).
