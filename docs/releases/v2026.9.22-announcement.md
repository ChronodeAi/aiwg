# AIWG 2026.9.22 - Doctor names installation drift

AIWG 2026.9.22 is a corrective release for provider reporting under stale
installations.

## What changed

- **Installation-drift diagnosis:** under installation identity drift,
  `aiwg doctor` resolves providers from the stale canonical install, so a
  provider that shipped after the install (muse) was reported as a bare
  `Unknown provider: muse`. The check now names the stale canonical install
  and points to `aiwg installation adopt`. No behavior change when drift is
  absent (#270).

## Try it

Update with `npm install -g aiwg@2026.9.22`. The
[versioning guide](../contributing/versioning.md) describes the stable-channel
policy.

The full change history is in the
[changelog](https://github.com/jmagly/aiwg/blob/v2026.9.22/CHANGELOG.md).
