# AIWG 2026.10.5 - Session catalog rebuild fixes

AIWG 2026.10.5 fixes four problems found while rebuilding session catalogs.
Rebuilds now keep history whose source files are gone, discovery uses the
providers configured for the workspace, redaction catches credential values
written on the line after their key, and `aiwg index refresh` recovers from a
preparation worker that runs out of memory.

## Rebuild a catalog without losing history

A fresh rebuild used to import only sources still on disk, so sessions whose
provider files had been pruned disappeared. Pass the previous catalog with
`--carry-forward` to keep them. AIWG reads the old catalog without changing it
and re-imports its sessions through the current redaction policy. The receipt
lists how many sessions came forward for each provider.

Try asking: "Rebuild the session catalog for this workspace and keep the history
from the current catalog."

## Discovery follows the workspace configuration

Discovery reads the providers in `.aiwg/aiwg.config`, and refresh re-reads them
each time. When the configured and recorded provider scope differ, discover,
refresh, import and doctor name the missing providers. Refresh never grants
access to new provider roots on its own; a workspace whose manifest predates
root grants needs one explicit `aiwg sessions discover`.

## Redaction covers values on the next line

Credential and environment patterns now match a value placed on the line after
`:` or `=`, with optional indentation or a backtick. A value on the next line
must be quoted or look generated, so lists and code fences in prose stay readable.
Re-import or rebuild existing catalogs to apply the new patterns to stored history.

## Index refresh survives large artifact sets

Index preparation workers now run as separate processes. A worker that exhausts
its memory is retried serially instead of stopping the whole refresh, and files
over 1 MiB are always prepared serially. Set `--index-workers 0` or
`AIWG_INDEX_WORKERS=0` to prepare everything serially.

## Upgrade

Update your installed AIWG package using your existing installation method, then
refresh the frameworks and addons deployed to your workspace. See the
[changelog](https://github.com/jmagly/aiwg/blob/v2026.10.5/CHANGELOG.md#2026105---2026-10-21)
for the release changes and the
[versioning guide](https://github.com/jmagly/aiwg/blob/v2026.10.5/docs/contributing/versioning.md)
for release publication details.
