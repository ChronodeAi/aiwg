# AIWG 2026.9.17 - Dataset contracts ship with the runtime

**Release date:** 2026-09-20

**Channel:** stable

AIWG's dataset runtime is now a supported public package entry. Consumers can
import `aiwg/dataset` from a clean installation, and the package carries the
pinned Fortemi capability contract needed to validate negotiation and wire
behavior without reaching into a source checkout.

## Contract qualification

The release package exercises 20 capability-version cases and 11 wire cases.
Cross-repository CI is pinned to the final signed Fortemi React Lane B source,
while live execution evidence remains explicitly bound to the released Fortemi
server rather than being inferred from package tests.

## Try it

```bash
npm install -g aiwg@2026.9.17
```
