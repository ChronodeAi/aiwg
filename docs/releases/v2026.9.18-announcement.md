# AIWG 2026.9.18 - Dataset conformance binds prior stable evidence

**Release date:** 2026-09-21

**Channel:** stable

Dataset Intelligence qualification now executes its adversarial and replay
corpora and verifies migration from the exact contract shipped in v2026.9.17.
The prior release fixture is bound to its tag, source commit, package version,
and SHA-256 digest, so migration evidence cannot silently drift with current
source.

## Executable qualification

The local matrix reports 13 passing cells and two controlled, mode-dependent
cells. Cross-repository qualification reports 14 passing cells and retains the
live-server cell as pending; this release does not reinterpret package or mock
coverage as live-runtime evidence.

JSONL discovery also rejects inputs beyond the configured nesting limit. The
million-record reader check now measures retained memory after garbage
collection in an isolated process, avoiding failures caused by unrelated test
suite allocation pressure while preserving the record-count and memory bounds.
