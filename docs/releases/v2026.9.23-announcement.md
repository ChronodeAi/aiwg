# AIWG 2026.9.23 - CPU bound gates isolated measurement

AIWG 2026.9.23 is a corrective release for the publish gate: the D05
load-harness CPU comparison now gates only isolated thread-CPU measurement
instead of the process-wide wall-clock fallback.

## What changed

- **Load-harness CPU gate:** the publish container runs Node 20, which lacks
  `process.threadCpuUsage`, so every publish run measured process-wide
  wall-clock CPU (runner plus sibling workers) against the fixed manifest
  bound and failed conforming code. The manifest CPU bound now gates only
  isolated thread-CPU results; the observed value stays recorded in
  resources for informational use.

## Try it

Update with `npm install -g aiwg@2026.9.23`. The
[versioning guide](../contributing/versioning.md) describes the stable-channel
policy.

The full change history is in the
