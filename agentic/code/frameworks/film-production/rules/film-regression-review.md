# Film Regression Review

## Scope

Applies before candidate promotion, downstream reuse, presentation as fixed, and final quality claims.

## Requirements

- Inspect the requested change and relevant invariants: character anatomy, object counts, prop identity, hand contacts, reach/clearance, support, attachment paths, set registration, depth, lighting, source text/art, and material detail.
- Pair a full-frame comparison with native-size defect and occlusion crops. For fixed cameras, use stable anchors or overlays when helpful. Checking only the repaired region misses regressions elsewhere.
- Play motion at real speed and frame-step critical transitions. Walk the planned event list: each contact once, on its target, in order, with matching counts and state changes. Listen to performance/sound in context. Contact sheets cannot certify smoothness, lip sync, continuous attachments, or temporal object identity.
- Compare adjacent shots and actual exported playback. Play at least one second either side of every cut at speed and frame-step the join; check pointer and finger position, key/button state, prop art and location, and that no action repeats, is skipped, or teleports. Check the intended range, dialogue continuity, transitions, and ending; an editor's successful render status is not viewing evidence.
- Use accurate evidence labels: generated means produced; candidate means awaiting or partly failing checks; verified means named checks passed for an exact version and inspected range. Do not extend verification beyond the evidence.
- Self-detected defects must update controlling state and hold affected downstream use. Writing “draft” in a receipt while continuing to use a known failing input does not satisfy the gate.
- Broad creative approval does not clear an acknowledged technical or quality failure. Preserve independent acceptance dimensions and reopen only those affected by a change.
- A defect found by the user rather than the review is an escaped defect. Record it, add its class to the review checklist for remaining shots, and re-check already passed shots for the same class.

## Required response

Maintain one compact review package with changed media, relevant comparisons, checks, residuals, and next action. Continue authorized repairs without automatic user-confirmation gates. If inspection is unavailable, disclose the limit and retain candidate status. These rules specify agent conduct, not automatically executable enforcement.
