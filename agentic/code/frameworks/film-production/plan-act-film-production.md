# Film Production Lifecycle

Use the six phase flows: develop, design, previs, generate, finish, deliver. They form an iterative lifecycle, not a requirement to repeat every phase for every note. The producer owns current state; specialists receive bounded shot scopes and immutable inputs. Parallelize independent research, sound preparation or review; serialize edits to the same frame/timeline and all approvals/submissions.

Start with `film-intake` on a new project and `film-resume` on continuation. A creative or physical correction follows `film-revise-with-impact`. The default proof is one representative frame/performance, then one authorized representative motion take. Expand only after acceptance on the dimensions needed by dependent work.

## Operational contract

Write the small current state under the resolved project artifact root; large media may remain in approved asset storage referenced by path and hash. Keep original datasets immutable. Each shot links story beat, action states, input hashes, selected performance, camera limits, exact layers and required approvals. Each generation records model/provider, task, settings, costs and results. Keep facts about technical capability separate from desired art direction.

Use film-review-gate to inspect the requested change and invariants, then full temporal playback before accepting motion. Failed evidence gates mean diagnose or repair, not reflexively ask permission. User review gates apply where requested. A paused goal remains paused until resumed; publishing is distinct from local delivery.

## Enforcement limits

Rules are agent procedures. The packaged state validator checks recorded identifiers, references and promotion conditions; it cannot see fingers, count actual handles, judge humor, verify rights, inspect hidden provider state or replace playback. False review data can pass structural checks. Record observation method and reviewer, including unavailable evidence.
