# Revise with impact

Entry: requested change, current state, affected shot and immutable masters.
1. Translate feedback into an observable acceptance condition; distinguish intentional effects from defects.
2. Find affected entities, shot versions, approvals and downstream takes. Mark impacted dimensions pending without discarding unrelated approved work.
3. Choose local edit/native layer/re-generation according to available tools and authority; retain the previous version. Do not repeatedly resample the entire scene for a small repair.
4. Use film-reference-edit or film-motion-coverage; after two same-method failures diagnose the method. Never bypass provider rejection.
5. Use film-review-gate for full-frame/crop and adjacent-shot checks. Character, object counts, support/contact, attachments, text and sound must survive.
6. Update current state only with actual evidence. One coherent review package replaces competing current documents.
Exit: changed target passes, invariants checked, affected dependencies reviewed or held. An attempted edit is not a fix.
