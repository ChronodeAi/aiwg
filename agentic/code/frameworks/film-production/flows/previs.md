# Film Previs

## Entry
Required reference views, script and draft constraints are available.

## Activities
Prove one representative frame and contextual voice/sound performance; assemble the animatic for comprehension, not final polish, and watch it at real speed. Mark every beat's treatment in current state. Inspect native crops and adjacent states.

Load with `aiwg show skill <name>`: film-reference-edit, film-performance-sound, film-review-gate.

## Outputs and owners
Representative candidate, selected audio, animatic, defects and dimension-specific review.
Owners: film-story-director, film-scene-supervisor, film-qc-reviewer.

## Exit evidence — FP-G03 Coverage lock
Criteria: `docs/taxonomy.md`, Acceptance gates and locks. Record `locks.coverage` before any paid motion generation; visual quality remains a separate dimension.

This gate evaluates evidence; it does not automatically demand a new user approval. Existing explicit scope/authority persists. On failure, stay in the affected phase, update current state and continue independent authorized work. A user pause blocks production. Frame, motion and delivery approvals apply to the recorded version and dimension only.
