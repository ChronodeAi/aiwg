# Resume film production

Read the current state and latest user steering, then only the affected shot and relevant skill. If production is paused, report next permissible work without starting media operations. Reconcile running/uncertain jobs by task ID before creating new jobs. Validate current source versions, unresolved defects and approval dimensions. Use the existing spend boundary; review history does not create a new permission request. Continue the next authorized action to a meaningful review milestone. Ask narrowly only if required scope, source or authority is absent. Output an updated current-state pointer and concise progress evidence; never mark an unfinished goal complete merely to replace its title.
