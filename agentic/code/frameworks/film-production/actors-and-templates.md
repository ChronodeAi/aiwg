# Roles and production artifacts

| Role | Owns | Reviews / handoff |
|---|---|---|
| film-producer | brief, current state, budget/authority, delivery | all handoffs and unresolved decisions |
| film-story-director | timed script, knowledge/clue ledger, performances | comprehension and causal coverage |
| film-continuity-supervisor | continuity bible and shot-state changes | character/set/prop, adjacent-shot invariants |
| film-scene-supervisor | source/layer plan, stills/motion generation receipts | input quality, supported model controls, contacts |
| film-editor-sound-supervisor | editable timeline, cue sheet and export | articulation, timing, mix, color and conform |
| film-qc-reviewer | independent review record | explicit defect scope and release evidence |

Templates: film-production-brief, film-production-state, film-continuity-bible, film-shot-record, film-generation-receipt, film-voice-cue-sheet, film-review-record, film-delivery-record. Producer owns integration; delegation never creates new spending, publishing or source-upload authority. Roles may be fulfilled sequentially by one agent; separate reviewers are useful for consequential acceptance, not mandatory overhead on every reversible edit.
