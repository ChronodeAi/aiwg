# Measure quality and speed

Record per accepted shot: provider calls and actual spend (currency/credits distinct), hands-on time, wait time, repair count, first-pass acceptance, defects escaped to user, and known-blocker promotions. Record unknown values rather than reconstructing false precision. Track scope/model/complexity changes so comparisons are not misleading.

A small pilot uses three related frames and one separately authorized motion test. Compare against a documented baseline. Target zero known-blocker promotion and zero duplicate props at review; diagnose after two same-method repair failures. These are operating targets, not empirical claims of improvement.

Keep one useful report per review milestone. Do not count messages, tokens or duplicate transcript lines as unique failures. Log quality costs as well as savings; local automation does not prove creative effectiveness.
