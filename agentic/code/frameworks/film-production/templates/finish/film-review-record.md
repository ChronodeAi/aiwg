# Film Review Record

Scope / input hashes / shot and timeline versions / reviewer / method / date:
Requested change / observable acceptance condition:
Full-frame result / native crops / adjacent frames / actual motion playback / contextual audio:
Event list walk: each listed event observed once, in order, at time / missing, repeated or extra events:
Cut boundaries played at speed (±1 s each): cut ID / carried states checked / repeats, skips or teleports:
Inserted art and screen text: native crops across the clip / fit, occlusion and layer order:

| Defect ID | Entity/time/region | Severity | Evidence | Affected dimension | Fix/hold | Downstream impact |
|---|---|---|---|---|---|---|

Review dimensions: story, blocking, visual_quality, performance, motion, edit, delivery.
Decision per dimension with exact version and evidence. Required user approval reference only where applicable. Label automated/manual/user evidence distinctly. Preserve explicit intentional effects. Candidate is not accepted; attempted is not fixed. Unknown or unavailable playback is a limitation, not a pass.

For machine-readable state, include reviewer_type and input_hashes (asset ID to SHA256) with every review. Defect resolution records the current shot_version, disposition_reviewer and disposition_evidence. An intentional/scope exception records its reason, basis and existing authority reference; minor residuals need disclosure. Do not turn the record format into new review requirements the user did not request.
