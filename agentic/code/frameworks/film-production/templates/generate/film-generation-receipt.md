# Film Generation Receipt

Run ID / shot version / operation / provider / model identifier + observed capability date:
Input versions/hashes / exact prompt and settings / duration/resolution/fps/audio / seed if returned:
Authority reference / estimate + currency / remaining budget / actual charge or unavailable:
Submission time / task ID / status / last reconciliation / error details (sanitized):
Output assets and SHA256 / selected take / candidate status / playback and crop checks:

For uncertain results, reconcile the same task before another submission. Same logical retry retains provider-supported idempotency identity. Do not treat an error as zero spend or a provider success as visual acceptance. Never persist credentials. A refusal is a boundary, not a prompt-optimization target.
