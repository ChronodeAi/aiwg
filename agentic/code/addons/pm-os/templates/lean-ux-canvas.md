# Lean UX Canvas

Author: Jeff Gothelf
Source: https://jeffgothelf.com/blog/the-lean-ux-canvas/
Book: Lean UX (O'Reilly, 3rd edition)
Use When: Validation
Don't Use When: Build, Exec Buy-In
Best For: Hypothesis Testing
Audience: Direct Team
Detail Level: Light
Time to Complete: 1 hour
Artefact: Canvas
Advantages: Hypothesis-driven, experiment-focused, surfaces riskiest assumptions, visual
Limitations: No specs, no narrative for stakeholders, not for eng handoff

---

*A canvas for teams working in conditions of uncertainty. Moves from business problem → hypotheses → experiments. Use when you need to validate assumptions before committing to build.*

*Note: This is presented as a document for Obsidian/markdown use. The original is a visual canvas — consider recreating in Miro or FigJam for collaborative sessions.*
