# Life Design Mapping exercise

## Step 1 — Walk the years

Get the person's current age, then go year by year from 18 to now. For each year, recall one moment of genuine happiness or satisfaction — a real memory that stands out, not a should.

Done when there is one genuine happy moment for each year from 18 to now (or an honest "none stands out" for a year).

## Step 2 — Describe each moment

For every moment, capture what they were doing, where they were, and who was around them.

Done when each moment has its what / where / who.

## Step 3 — Find the recurring themes

Read across the moments and mark what repeats — the activities, environments, roles, and people that show up again and again.

Done when the repeated elements across moments are marked.

## Step 4 — Name the key patterns

Distill 3–5 patterns that consistently produce satisfaction for this person — specific enough to act on ("building something with a small team," not "work").

Done when there are 3–5 specific, evidence-backed patterns.

## Step 5 — Translate into a life-design insight

Write what these patterns reveal about the life they'd want to build — the things to arrange for more of, stated concretely.

Done when the insight names concrete things to build more of, each traceable to a pattern.

## Output

Resolve the save path with `bash bin/memory/resolve-project.sh --project {slug} --json`, then write to `{project_path}/YYMMDD-life-design-mapping-{name-slug}.md`. Never hand-build the path.

The doc holds: the happy moments by year with what/where/who, the recurring themes, the 3–5 key patterns, and the life-design insight.
