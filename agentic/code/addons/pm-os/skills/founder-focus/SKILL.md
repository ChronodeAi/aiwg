# Narrow, simplify, then push to maximum intensity

## Step 1 — Narrow the focus

From the founder's situation, name 1-3 priorities that actually matter right now, and explicitly name what's being set aside to make room for them.

Done when 1-3 priorities are named with a reason each is crucial, and the deprioritized items are named too.

## Step 2 — Find the common-sense solution

For the top priority, propose one simple, unsophisticated solution a person could explain in one sentence (e.g. "make 30 sales calls a day") — not a clever system, the obvious thing done consistently. Suggest one concrete way to track it daily.

Done when the solution is simple enough to state in one sentence, and has a concrete daily tracking method.

## Step 3 — Push to maximum intensity

Take the common-sense solution from Step 2 and describe what an extreme, far-beyond-comfortable version of executing it would look like. Name 2-3 specific high-intensity actions, not a vague call to "work harder."

Done when 2-3 specific, extreme actions are named, each a concrete escalation of the Step 2 solution rather than generic hustle advice.

## Output

Resolve the save path with `bash bin/memory/resolve-project.sh --project {slug} --json`, then write to `{project_path}/YYMMDD-founder-focus.md`. Never hand-build the path — save is optional for a one-off coaching exchange.

The doc holds: the narrowed priorities, the common-sense solution with tracking method, and the high-intensity actions.
