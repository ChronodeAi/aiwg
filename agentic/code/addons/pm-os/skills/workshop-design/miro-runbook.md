# Miro runbook

Board mechanics for an intermediate Miro user. Skip entirely for in-person-only sessions — say "not applicable" rather than inventing a digital equivalent.

## Board prep

Create the board. Add a cover frame with title, goal, agenda, and ground rules, then lock the static elements (right-click → **Lock**). Set sharing deliberately: edit for participants, view for observers.

## Frames

Pre-create one labeled, numbered frame per agenda step — `1-Intro`, `2-Themes`, `3-Ideate`, `4-Prioritize`, `5-Decide`, `6-Wrap` — at consistent sizes. Load and relabel Miro templates where they fit: Affinity Diagram, Prioritization Matrix 2×2, Kanban, Crazy 8s.

## Sticky notes

Color-code by pod or role. Tag by theme and owner. Use **Bulk mode** to pre-seed prompts. Lock the headings so they survive the session.

## Breakouts

Duplicate a master frame per pod and label them Pod A, Pod B, Pod C. Share pod assignments and paste the board link into each breakout chat. Set the return protocol up front: when the timer ends, everyone returns to the main room.

## Timer and voting

Run the **Timer** for every round with an audible alert and a 30–60 second buffer between rounds. Launch **Voting** (Apps → Voting) with anonymous ballots; state votes per person and the criteria being voted on — impact, feasibility, confidence.

## Prioritization and synthesis

Insert a 2×2 with labeled axes, or an ICE/RICE table, or Kanban swimlanes. Snap ideas into position and use align/distribute. Cluster with lasso select → **Group**, then convert the top clusters into titled cards.

## Export and handoff

**Export → PDF/PNG** including frames. Create a decision-log text box. Assign owners with **@mentions** and due dates. Add a Parking Lot frame for out-of-scope items.

## When it lags

Hide cursors and avatars, collapse frames, reduce widgets, or fall back to capturing in chat. If lag eats the clock, extend one convergent step and drop a later optional one.
