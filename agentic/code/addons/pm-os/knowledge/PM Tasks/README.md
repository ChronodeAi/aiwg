# PM Tasks — Drill Index

25 exercises for product managers to practice their craft, sharpen skills, and build muscle memory. Used by the `/drill` command to match tasks to what you need right now.

## How to use

- Run `/drill` to get a personalized recommendation based on a quick diagnostic
- Browse the index below to pick a drill manually
- After completing a drill, your rep is logged in `📂 Context/Work/Drills/`
