# Rapid Impact Sizing

Theme: Features, Prioritisation, Roadmap
Edition: 99
In the newsletter: https://nurijanian.substack.com/i/137499988/actionable-tasks-less-than-minutes-each
Source: https://www.news.aakashg.com/p/an-advanced-guide-to-impact-sizing

Conduct a rapid impact sizing exercise for an upcoming feature.

1. Identify key metrics (e.g., DAU, MAU, Revenue).
2. Make quick but data-informed assumptions for user adoption and engagement.
3. Sketch a simple model on Google Sheet to estimate impact on chosen metrics.
4. Identify the weakest/riskiest assumption; flag it for more rigorous analysis later.
