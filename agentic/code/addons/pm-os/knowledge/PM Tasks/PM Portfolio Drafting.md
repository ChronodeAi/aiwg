# PM Portfolio Drafting

Theme: Career, Job Search, Resume
Edition: 99
In the newsletter: https://nurijanian.substack.com/i/137499988/actionable-tasks-less-than-minutes-each
Source: https://aatir.substack.com/p/how-to-create-a-product-manager-portfolio

Allocate 30 minutes on Monday to draft the outline of your Product Manager Portfolio using a tool like Miro for mind mapping. Focus on 3-4 key initiatives or features you've worked on. For each, jot down context, your specific contribution in STAR format (Situation, Task, Action, Result), and any possible visual aids (e.g., interface screenshots, flowcharts).
