# Improve Your Writing Clarity In Just 1 Prompt

Theme: GPT, PM Craft, Writing
Edition: 102
In the newsletter: https://nurijanian.substack.com/p/ultimate-guide-to-opportunity-solution
Source: https://nurijanian.substack.com/p/flesch-kincaid-genius-how-to-drastically

- Open the [**Flesch Kincaid Genius GPT**](https://chat.openai.com/g/g-NL9K4E6Gj-flesch-kincaid-genius).
- Take a piece of your writing you want to simplify.
- Ask it to rewrite it for the 6-th grade (or you can choose whatever grade feels right).
- Enjoy the revised writing.

You can also ask it to calculate the Flesch-Kincaid score for any piece of writing and it will do it using the Code Interpreter.

I find myself using this tool every time I write anything that aims to explain and convince (slide decks, narratives, etc.).

But you can also use it on Slack messages and emails.
