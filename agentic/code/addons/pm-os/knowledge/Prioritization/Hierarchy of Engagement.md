# Hierarchy of Engagement

Use When: Consumer Product, Established Product, Growth Stage, Have Usage Analytics
Author: Sarah Tavel (Benchmark)
Don't Use When: Building a New Product, No Analytics, B2B Enterprise, Vision Setting Only
Best for Prioritising...: Features, Initiatives/Epics
Advantages: Data-Driven, Sequences Work Logically, Tied to Business Outcomes
Limitations: Requires Good Analytics, Doesn't Work Without a Clear Core Action, Won't Help Set Vision

Read Case Study: https://sarahtavel.medium.com/the-hierarchy-of-engagement-expanded-648329d60804

## Description

Sarah Tavel's Hierarchy of Engagement frames prioritization as a ladder: you should only move up the ladder once the rung below is solid. Each rung asks a progressively higher-order question about user behavior.

**The ladder (bottom to top):**
1. **Core action completion** — Are users completing the fundamental action your product enables? (e.g., sending a message, completing a booking, posting a photo)
2. **Retention** — Are users returning to complete the core action again?
3. **Habit** — Is the core action becoming habitual and embedded in their routine?
4. **Network effects / defensibility** — Are users creating value for other users?

**How to prioritize**: Any feature request can be framed as an answer to the question at one of these rungs. Before prioritizing features at a higher rung, confirm the lower rung is healthy. If core action completion is low, retention features are premature.

**Diagnostic use**: If you're not sure what to work on, look at where the ladder breaks down. That's where the highest-leverage work is.

Most effective for consumer products with clear core actions and sufficient analytics to measure completion rates at each level.
