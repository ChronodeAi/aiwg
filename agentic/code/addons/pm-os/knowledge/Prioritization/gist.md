# GIST

Use When: B2B, Internal Product, Sequence Work, Vision Setting/Long-Term Roadmapping
Author: Itamar Gilad
Don't Use When: In Delivery, Internal Product, Mid/Low Influence, Need Quick Decisions
Best for Prioritising...: Initiatives/Epics, Lanes/Themes
Artefact: Diagram, Spreadsheet
Advantages: Lightweight, Not Dogmatic
Limitations: Requires Your Goals First, Won't Help Set Goals, Won't Help With Delivery
Read Case Study: https://itamargilad.com/gist-framework/

## Description

GIST is a system for planning. GIST stands for Goals, Ideas, Step-projects, and Tasks. 

The system is designed to be lightweight and easy to change, and to improve team velocity and autonomy.

**Key Aspects:**

- Plans should specify goals, not solutions.
- Ideas should be collected in an Idea Bank and prioritized using evidence.
- Step-projects should be used to test ideas.
