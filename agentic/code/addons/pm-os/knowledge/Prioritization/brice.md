# Description

BRICE scoring adds a new category called **Benefit** to the existing RICE scoring method. Benefit measures how much value a feature or function will bring to the user and the business. The article above explains how to use BRICE scoring and provides an example of comparing two features using this method. But it’s very similar to: 

[RICE](RICE%20d3c9c8e5c14944e1b6f41c15b962101d.md)
