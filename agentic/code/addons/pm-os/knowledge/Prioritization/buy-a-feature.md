# Buy a Feature

Use When: Building a New Product, Limited Influence, Prioritise Opportunities
Author: Luke Hohmann
Don't Use When: In Delivery, Mid/Low Influence, Vision Setting/Long-Term Roadmapping
Best for Prioritising...: Features
Artefact: Diagram
Advantages: Lightweight, Not Dogmatic
Limitations: Need To Know Problems First, Requires Your Goals First, Won't Help Set Goals
Read Case Study: https://www.uxforthemasses.com/buy-the-feature/
Workshop: Buy a Feature (../Workshops%20&%20Tools/Workshops/Buy%20a%20Feature%20afef4178809643b5af347f143d0d748f.md)

# Description

Buy a feature is a prioritization technique that helps you understand what your customers value most in your product. You give your customers a fixed budget and a list of features with different costs. You ask them to buy the features they want for your product. You observe their choices and preferences. You use this data to guide your product development and roadmap.
