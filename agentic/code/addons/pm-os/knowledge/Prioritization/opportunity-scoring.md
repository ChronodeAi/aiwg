# Description

A way of visualizing the impact of user experience of any given use case based on its opportunity score, while helping in the product decision making process by providing a better sense of priorities. The opportunity score is calculated by multiplying the importance and satisfaction ratings of each user need. The article uses an example of a travel app to illustrate how to plot the use cases on a matrix with four quadrants: Must Have, Performance, Excitement and Indifferent. The method helps to identify which use cases are more valuable and feasible for the product, and which ones can be deprioritized or eliminated.
