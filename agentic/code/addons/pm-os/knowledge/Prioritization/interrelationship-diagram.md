# Interrelationship Diagram

Use When: Internal Product, Limited Influence, Need Quick Decisions, Sequence Work
Author: Ryan Singer
Don't Use When: Vision Setting/Long-Term Roadmapping
Best for Prioritising...: Initiatives/Epics, Tasks
Artefact: Diagram
Advantages: Lightweight, Not Dogmatic
Limitations: Requires Your Goals First, Won't Help Set Goals
Read Case Study: https://world.hey.com/rjs/1-unfolding-the-interrelationship-diagram-5a79e3fc

## Description

This method is more universal than most. That’s why it doesn’t have much in **Don’t Use When.** 

You can use it at multiple levels, by yourself or with your team (although it’s still best with others’ input).

The challenge can occur when you don’t understand the options deeply, because it would be hard to understand what options can unlock other options. But the beauty of this method is that it’s so quick and easy, that you can always do it again.

I would caution against using it for long-term roadmapping because it is such a quick decision-making tool.

In saying that, you probably want to apply multiple lenses when roadmapping beyond a quarter anyway. So you can still use it to get started and go into more detail elsewhere.

## **Steps to Create an Interrelationship Diagram**

1. Define the problem or issue clearly. Write it as a concise statement.
2. Identify factors related to the problem through brainstorming. Aim for 5-10 key factors.
3. Arrange the factors in a circular pattern around the central problem statement.
4. Analyze relationships between factors:
    - For each pair of factors, determine if there's a cause-effect relationship.
    - Draw arrows to show these relationships, pointing from cause to effect.
    - Use solid lines for strong relationships and dashed lines for weaker ones.
    - Only draw arrows in one direction - the stronger influence.
5. Count and label arrows:
    - Count incoming and outgoing arrows for each factor.
    - Write these counts next to each factor (e.g., "3 in, 2 out").
6. Analyze the diagram:
    - Factors with mostly outgoing arrows are likely root causes or drivers.
    - Factors with mostly incoming arrows are key effects or outcomes.
    - Factors with many connections (both in and out) are often key elements.
