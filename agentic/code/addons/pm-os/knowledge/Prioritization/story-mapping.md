Use When: Building Team Consensus, Building a New Product, Need Quick Decisions, Sequence Work, Vision Setting/Long-Term Roadmapping

# Description

Story mapping is a way to plan your product. You make a big picture of what you want to do. You break it down into smaller pieces. You prioritize the most important pieces. You work on them one by one until you have a good product.

Here is an example of story mapping for a free online educational kids game:

- The product is the game. The outcome is for the user to find and play the game.
- The user activities are: Search for game, Select game, Play game, Rate game, Share game.
- The user stories are:
    - For Search for game: Enter keywords, Browse categories, Filter results, Sort results.
    - For Select game: View details, Read reviews, Watch preview, Start game.
    - For Play game: Learn instructions, Choose level, Control character, Collect points, Complete level.
    - For Rate game: Give stars, Write feedback, Submit rating.
    - For Share game: Copy link, Choose platform, Send message.

The priority is based on the value and effort of each user story. The most important and easy ones are at the top left. The least important and hard ones are at the bottom right.

The slices are groups of user stories that can be delivered in iterations. For example:

- Slice 1: Enter keywords + View details + Start game + Control character + Complete level
- Slice 2: Browse categories + Learn instructions + Collect points
- Slice 3: Filter results + Read reviews + Give stars
- Slice 4: Sort results + Watch preview + Write feedback
- Slice 5: Choose level + Rate game + Copy link
- Slice 6: Share game
