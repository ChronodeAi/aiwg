# Description

Value vs. Risk is a model for product prioritization that compares the value of what is to be done with the risk involved in doing it. Value is how much benefit the product will deliver to the customers or users. Risk is how uncertain or difficult it is to deliver that value.

The model uses a quadrant to plot each feature or item on a scale of high or low value and high or low risk. The features in the top left quadrant are high-value and low-risk, meaning they are easy to deliver and have a lot of benefit. These are the features that should be done first. The features in the bottom right quadrant are low-value and high-risk, meaning they are hard to deliver and have little benefit. These are the features that should be done last or not at all.

The model helps product teams prioritize features that will maximize customer satisfaction and minimize waste. It also helps them identify and address risks early on, before they become bigger problems later. By using Value vs. Risk, product teams can make better decisions about what to build and when to build it.
