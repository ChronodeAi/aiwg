# Charcuterie Board

Use When: Building Consensus, Established Product, Balanced Roadmap Needed, Building a New Product
Author: Jackie Bavaro
Don't Use When: In Delivery, Need Quick Decisions, Single-Priority Crisis Mode
Best for Prioritising...: Themes/Lanes, Initiatives/Epics
Advantages: Prevents Over-Indexing, Easy to Communicate, Builds Team Consensus, Handles Tech Debt Explicitly
Limitations: Equal Portions Can Be Arbitrary, Won't Score Individual Features, Doesn't Incorporate Impact Data

Read Case Study: https://jackiebavaro.substack.com/p/the-charcuterie-framework-for-roadmap

## Description

Jackie Bavaro's Charcuterie Board framework recommends treating the roadmap like a well-curated charcuterie board: a balanced variety of items in roughly equal or deliberate proportions, with no single item dominating.

The core idea: most roadmaps fail not because they have the wrong items, but because they have the wrong *balance* — too much new feature work, not enough tech debt, no user-requested improvements, or constant firefighting crowding out strategic work.

**Typical Charcuterie Board categories**:
- New features (growth/expansion)
- Customer-requested improvements
- Tech debt and platform health
- Quality and bug fixes
- Exploratory/discovery work

The framework doesn't score or rank items — it sets the *allocation* first, then lets the team fill each bucket with the best items. You debate the ratios, not individual features.

Most effective when you're presenting a roadmap to leadership and need to demonstrate balance, or when one category (usually tech debt or user requests) is systematically neglected.
