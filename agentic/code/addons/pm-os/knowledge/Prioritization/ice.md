# Description

The ICE framework, developed by Sean Ellis, is used for prioritizing features and initiatives/epics in internal product development when quick decisions are needed and a "good enough" level of accuracy is acceptable. It involves evaluating each item based on three factors: impact, confidence, and ease. The scores for each factor are added together to give an overall score, which is used to prioritize items. This framework is not recommended for vision setting or long-term roadmapping, and is best suited for fast-paced, high-velocity development environments and high-growth stages.
