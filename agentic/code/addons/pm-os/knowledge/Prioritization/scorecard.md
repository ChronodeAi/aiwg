# Description

This is a tool to help product managers evaluate and prioritize their product ideas and features. The scorecard is based on four criteria: **value**, **feasibility**, **usability** and **business fit**. Each criterion has a set of questions that product managers can use to rate their ideas on a scale of 1 to 5.

The article explains how to use the scorecard in four steps:

1. List your product ideas or features in a spreadsheet or a tool like Aha! software[**1**](https://www.aha.io/blog/introducing-the-new-product-value-scorecard).
2. Rate each idea or feature on each criterion using the questions provided in the article. You can also add your own questions or modify the existing ones to suit your context.
3. Calculate the total score for each idea or feature by adding up the ratings for each criterion. You can also apply weights to different criteria if you want to emphasize some aspects more than others.
4. Sort your ideas or features by their total score and use the results to decide which ones to pursue, validate, prototype, test or discard.
