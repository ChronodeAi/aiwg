**Shift Swap Project Charter**  
Shift Swap MVP Project

**Problem Statement**  
How can we decrease the number of shifts that get dropped and increase access to additional shift opportunities for employees?

**Approach**  
We’ll build a web-based system that allows managers to broadcast available shifts to relevant employees via SMS. The interface for employees will be primarily SMS so they can respond with Yes or NO to accept or reject the shift.

**Project Timeline**  
Our goal is to have a Minimum Viable Product (MVP) complete and live within 30 days. We will most likely pilot a functional version within two weeks.

**Goals & Success Metrics**

| Goal | Decrease the number of lost shifts |
